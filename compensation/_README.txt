Папка файлов промеров (компенсация растискивания).

Один файл = один полимер / процесс (толщина, экспонирование, линиатура).
Имя файла (без расширения) показывается в списке «Компенсация» в окне программы.
Файлы, начинающиеся с «_», в список не попадают.

Как получить файл:
 1. В программе: «Шкала для промера» -> calibration_*.tif и template_*.csv
    (при тех же dpi, lpi, размере FM-элемента, что и в работе).
 2. Вывести шкалу на форму этого полимера, изготовить форму как обычно.
 3. Промерить плашки (прибор для форм или по оттиску), вписать % в колонки am / fm / line.
 4. Сохранить шаблон под именем полимера, например  Polymer_X_1.14_2400.csv,
    и положить сюда (или кнопка «Добавить промер…»).
 5. «Контрольная шкала» с выбранной компенсацией — проверка: на форме должны получиться
    заданные проценты.

Формат: CSV, разделитель «;», десятичная запятая допускается.
  target;am;fm;line          — задано / измерено по каждому растру
  колонка measured           — одна кривая на все растры
  колонка aim (необязательно) — желаемый результат (по умолчанию = задано)
  # min_dot_am: 2            — мин. точка (%), перекрывает настройку
